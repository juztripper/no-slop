# NO SLOP 0.1.0 — developer preview

Make room for worthwhile content. NO SLOP is an open-source Chromium extension for low-quality AI content, clickbait, spam and content farms. This first preview is for developers who want to try it locally and help improve it.

## What is included

- Two independent filters for AI filler and classic low-quality content. AI use alone is not a reason to filter.
- Reversible censorship with a reason and Show control, or whole-item hiding. Paragraphs and dependent replies retain context.
- Filter strength, per-site controls, domain exceptions, pause and restore.
- Site adapters, an opt-in text-only detector using Jev through OpenRouter, and a locally runnable settings preview.
- TypeScript source, deterministic regression tests, authored evaluation examples, issue templates and contribution guidance under AGPL-3.0-only.

## Install and bring your own key

1. Download and extract `no-slop-0.1.0-chromium.zip`.
2. In Chrome or Edge, open the extensions page, enable Developer mode, and load the extracted folder as an unpacked extension.
3. Download or clone the matching source. With Node.js 24+, run `npm ci`, copy `.env.example` to `.env`, and set your own `OPENROUTER_API_KEY`.
4. Set a provider spending limit, then run `npm run server:dev`. Keep the detector running while browsing.
5. In NO SLOP's Privacy & service settings, test `http://localhost:8787`, review the data flow, enable analysis, and refresh existing tabs.

The project does not supply an API key, credits or a hosted detector. Provider usage is billed to your own account. Your OpenRouter key stays in the detector environment; the extension only stores the detector address and optional access token. The interface preview and deterministic tests need no key.

See [setup and troubleshooting](https://github.com/juztripper/no-slop/blob/v0.1.0/docs/DEPLOYMENT.md), [privacy](https://github.com/juztripper/no-slop/blob/v0.1.0/PRIVACY.md), and the [verification record](https://github.com/juztripper/no-slop/blob/v0.1.0/docs/VERIFICATION.md).

## Known limits

This is a pre-release, not a browser-store release. Site adapters cover recognized markup; logged-in feeds and account-specific layouts still need broader qualification. Unknown layouts, uncertain judgments and provider failures leave content visible. Images and video/audio playback are not analyzed. A local detector still sends selected text to OpenRouter/Jev. The committed evaluation sets are authored development examples, not general accuracy claims.

## Build this with us

The most useful early contributions are small and concrete: a sanitized site fixture, a false-positive regression, keyboard or screen-reader improvements, multilingual examples, or clearer setup instructions. Start with [CONTRIBUTING.md](https://github.com/juztripper/no-slop/blob/main/CONTRIBUTING.md), [report a bug](https://github.com/juztripper/no-slop/issues/new?template=bug.yml), [share a detection example](https://github.com/juztripper/no-slop/issues/new?template=detection.yml), or send a pull request with evidence of the resulting behavior.

The ZIP includes the extension, third-party licenses, install instructions and privacy notes. `SHA256SUMS` records the checksum of the release download. Source is available with the matching tag.
